### Сделать своё мини-расширение (Самый чистый способ)
Если не хочется трогать HTML сайта, можно за 2 минуты собрать собственное расширение для браузера. Оно будет внедрять ваш JS-файл на нужный сайт автоматически на постоянной основе.
1. Создайте пустую папку на ПК.
2. Создайте в ней файл manifest.json и вставьте этот текст:json
   ```
   {
     "manifest_version": 3,
     "name": "My Script Injector",
     "version": "1.0",
     "content_scripts": [
       {
         "matches": ["https://*.example.com/*"],
         "js": ["myscript.js"],
         "run_at": "document_end"
       }
     ]
   }
   ```
   Замените https://*.example.com/* на адрес сайта, где должен работать скрипт (например, https://*.vk.com/* или <all_urls> для всех сайтов вообще).
3. В этой же папке создайте файл myscript.js и напишите в него ваш скрипт.
4. Откройте браузер, перейдите по ссылке chrome://extensions/ (или настройки -> Расширения).
5. Включите тумблер «Режим разработчика» (Developer mode) в правом верхнем углу.
6. Нажмите появившуюся кнопку «Загрузить распакованное расширение» (Load unpacked) и выберите вашу папку.
